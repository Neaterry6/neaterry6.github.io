Languages

When a project is big enough that types pay for themselves.

SQL

Postgres for anything with real state.

Backend

Express

Default for REST APIs. Boring, which is the point.

Supabase

Postgres, auth, storage and realtime in one. Row-level security does the access control.

Baileys

WhatsApp protocol library — powers broken-wa-api and the bots.

Frontend

Surprisingly far. Most of these sites ship no framework at all.

Tailwind

Utility classes, no CSS architecture to maintain.

Next.js

When a project needs routing, SSR or both.

Static HTML, fast and cheap.

Only when a page genuinely needs a browser.

yt-dlp

Media extraction. Nothing else comes close.
